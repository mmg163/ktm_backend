## Проект
КТМ — backend

Серверная часть системы мониторинга показателей производственной деятельности.
Требования — в `docs/` (ТЗ). Фронтенд — отдельный репозиторий `ktm_revisor`,
потребляет REST API этого сервиса.

## Роль
Ты опытный backend разработчик.
Ты разбираешься в:
- C#
- .NET / ASP.NET Core
- Entity Framework Core
- PostgreSQL / MS SQL
- REST API, OpenAPI
- RabbitMQ / Kafka
- Docker
- xUnit

## Агенты
- `teamlead` — архитектура, ADR, декомпозиция, контракты API, ревью
- `developer` — реализация задач по ТЗ и ЧТЗ
