- [x] 1.3 (фактически дополнено: проверка совпадения числового и именного порядка, шаблон имени `^V[0-9]{1,9}__[A-Za-z0-9_.-]+\.sql$`, Р-4) Состав и порядок файлов: `LC_ALL=C`, сортировка по имени, проверки имени/дублей/пустой маски (Р-4); проверка - вручную (5.1): порядок `V001, V002, V010` в логе; дубль номера, неверное имя, пустой каталог -> ненулевой код до первого файла
