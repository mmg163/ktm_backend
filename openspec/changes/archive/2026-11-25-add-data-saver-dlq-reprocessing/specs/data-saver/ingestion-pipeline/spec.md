# Spec Delta

Изменяет требование «Порт обработки ошибок записи (C6)» капабилити `data-saver/ingestion-pipeline`
(`openspec/specs/data-saver/ingestion-pipeline/spec.md`): заглушка «ничего не теряет и блокирует партицию» заменена политикой
бюджета попыток и изоляции (`dead-letter`, ADR-0006). Порт `IWriteFailureHandler` сохраняется.

## MODIFIED Requirements

### Requirement: Порт обработки ошибок записи (C6)

При ошибке записи класса «данные» (нарушение ограничений, недопустимые данные) Data
Saver ДОЛЖЕН вызывать порт обработки ошибок записи. Принятое портом решение «увести сообщения» (`DeadLetter`) допустимо только для сообщений
текущей пачки и только после durable-сохранения этих сообщений; такое решение исключает сообщения из записи и позволяет зафиксировать их offset.
Решение «повторить» ДОЛЖНО расходовать бюджет попыток (`DataSaver__Dlq__MaxAttempts`, капабилити `dead-letter`): после его исчерпания Data Saver ДОЛЖЕН изолировать
ядовитое сообщение и опубликовать его в `ktm.events.dlq`, не теряя остальные сообщения пачки. Реализация порта по умолчанию (`BlockingWriteFailureHandler`) возвращает «повторить»;
при `DataSaver__Dlq__Enabled=false` поведение прежнее: повтор с нарастающей паузой без предела, состояние `Degraded`, лог Error.
Временные ошибки соединения порт НЕ вызывают.

#### Scenario: Временная ошибка

- **WHEN** запись не удалась из-за недоступности БД
- **THEN** порт обработки ошибок записи не вызывается

#### Scenario: Ошибка данных

- **WHEN** запись пачки не удалась из-за нарушения ограничения БД
- **THEN** порт вызывается с контекстом пачки и ошибки; пока бюджет попыток не исчерпан, пачка не теряется и
  offset не фиксируется; после исчерпания ядовитое сообщение уходит в `dlq`, остальные записываются

#### Scenario: Порт вернул DeadLetter

- **WHEN** порт вернул `DeadLetter` для сообщения текущей пачки
- **THEN** сообщение исключено из записи, остальные записаны, offset зафиксирован (поведение не изменилось относительно прежнего контракта порта)

#### Scenario: Решение для чужих сообщений

- **WHEN** порт вернул `DeadLetter` для сообщений не из текущей пачки либо без прироста набора
- **THEN** решение трактуется как «повторить» (расходует бюджет), цикл не вращается без пауз
