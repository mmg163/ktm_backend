## Источник результатов

## Ограничения и оставшаяся приёмка

Локальные Docker-прогоны подтверждают только перечисленные сценарии. Они не подтверждают NFR из [ТЗ, п. 7.1](../07-нефункциональные-требования.md): 500 событий/с и задержку до отражения события. Числовых результатов производительности нет; приёмочный замер требуется на целевом контуре (`add-infrastructure-topology`).

Перед закрытием 8.2 проверить конфигурацию ingress/периметра и доступность порта Data Saver с другой машины/внешнего контура: **`/admin` не опубликован наружу, порт Data Saver недоступен извне**. Проверка не требует запросов к admin API/UI. Отсутствие опубликованного порта в compose само по себе не подтверждает защиту внешнего периметра стенда.

Также в 8.2 остаётся прогон DLQ → исправление → повторная обработка через Core на dev-стенде по [протоколу выкладки](data-saver-deployment-dev.md). Ранее выполненный локальный тест 6.3 не считается проведённой выкладкой на dev-стенд. Sync/archive (8.3) допускаются после 8.1–8.2 и решения лида.
