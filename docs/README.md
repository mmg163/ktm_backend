# Техническое задание

Система мониторинга показателей производственной деятельности
(Система управления и контроля операционной эффективности персонала)
для ООО «КуйбышевТелеком-Метрология».

Документ описывает минимально необходимый и обязательный объём функциональных,
технических, интеграционных и эксплуатационных требований к Системе.

Частные технические задания (ЧТЗ) разрабатываются на каждый этап исключительно
в целях детализации требований и не могут уменьшать объём требований, ухудшать
характеристики Системы, исключать предусмотренный функционал либо изменять
критерии приёмки.
